# GRC102 – Information Security Governance

**Case Study:** GlobalHealth Connect (GHC)  
**Focus:** Information Security Governance, Risk, Compliance & Board Oversight  
**Project Type:** GRC Academic Portfolio Project  
**Author:** Kefilwe Matake

## Project Overview

This project presents an information security governance assessment and improvement plan for **GlobalHealth Connect (GHC)**, a fictional mid-sized health-tech organization.

The assessment identifies governance weaknesses following rapid growth and acquisitions, including unclear security ownership, inconsistent policies, reactive risk management and limited Board-level reporting.

The project proposes a practical governance model to strengthen accountability, risk oversight, compliance readiness and business alignment.

##  Objectives

- Assess the current security governance state
- Identify governance and accountability gaps
- Design an information security governance structure
- Develop a RACI matrix and Security Charter
- Analyze security metrics and priority risks
- Establish a Security Steering Committee
- Assess governance maturity
- Develop a 12–18 month improvement roadmap
- Translate technical risks into business-level decisions

##  Key Findings

GHC's primary governance weakness is the lack of a coordinated system connecting:

**Accountability → Risk Management → Decision-Making → Oversight → Business Reporting**

Key issues identified include:

- Unclear security ownership
- Limited Board-level oversight
- Inconsistent policies
- Reactive risk management
- Weak cross-functional accountability
- Increasing high-risk security incidents
- Declining critical vulnerability remediation
- Compliance activities that are primarily audit-driven

##  Security Posture

**Overall Security Posture: 🔴 RED**

| Metric | September | February | Change |
|---|---:|---:|---:|
| Phishing Attempts | 150 | 320 | +113.3% |
| Malware Incidents | 25 | 50 | +100% |
| Critical Vulnerabilities Patched | 67% | 55% | -12 pp |
| Security Training | 45% | 70% | +25 pp |
| High-Risk Incidents | 2 | 7 | +250% |

The analysis indicates increasing threat activity and realized risk alongside declining critical vulnerability remediation.

##  Proposed Governance Model

**Board of Directors → CEO → Information Security Governance Function → Security Steering Committee**

The model establishes clear accountability across:

- Executive leadership
- Technology
- IT
- Compliance
- HR
- Finance
- Business and technical SMEs
