## 📌 Overview

This practical laboratory focuses on developing a structured and maintainable **information security policy framework** for NexusTech Solutions, a 250-person software organisation serving financial and healthcare clients.

The scenario identified weaknesses in NexusTech's existing five-year-old **"IT Rules"** document, which combined management requirements, technical controls, operational procedures and recommendations.

The assignment addresses these issues by developing governance artefacts that clearly distinguish between **policies, standards, procedures and guidelines**, while establishing ownership, accountability, communication, review and continuous improvement.

---

## 🎯 Objectives

The practical laboratory demonstrates the ability to:

* Develop a structured security policy hierarchy
* Distinguish between policies, standards, procedures and guidelines
* Translate security requirements into practical organisational rules
* Establish clear roles and responsibilities
* Develop an Acceptable Use Policy
* Develop a User Access Request Procedure
* Create a security communication and training plan
* Establish policy review and maintenance requirements
* Define measurable governance and awareness objectives
* Support auditability and continuous improvement

## 🔐 Key Governance Model

The assignment applies the following documentation hierarchy:

```text
Governance
    ↓
Policy
    ↓
Standard
    ↓
Procedure
    ↓
Implementation & Evidence
```

Guidelines provide recommended practices that support implementation.

### Core Principle

> **Policy defines what and why; standards define mandatory requirements; procedures define how; guidelines provide recommended practices.**
